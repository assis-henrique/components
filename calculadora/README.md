# 🧮 Calculadora React

Projeto desenvolvido em **React** para realizar operações matemáticas básicas.

## 🚀 Funcionalidades

* Primeiro número
* Segundo número
* Operações: `+`, `-`, `*` e `/`
* Botão **Calcular**
* Botão **Limpar**
* Exibição do resultado
* Validação de divisão por zero

## 🛠️ Tecnologias

* React
* JavaScript
* HTML
* CSS
* Vite

## 📚 Conceitos aplicados

* Componentização
* `useState`
* Eventos (`onChange` e `onClick`)
* `switch`
* Condicionais
* CSS

## ▶️ Como executar

```bash
npm install
npm run dev
```
